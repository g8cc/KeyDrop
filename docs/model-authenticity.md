# 模型真伪检测——调研与方案设计

> 背景:中转站"挂羊头卖狗肉"——声称 claude-opus 实际路由到便宜开源模型。
> 本文回答:哪些校验方法**不可被中转站规避**,哪些能被规避(因此不作为定罪依据),
> 以及 KeyDrop 的分级落地方案。

## 0. 核心原则:只有"长在权重里的能力"不可伪造

中转站能控制的:响应包装(JSON 字段/头)、usage 计数、身份自述、错误形状 —— 全部可伪造。
中转站不能控制的:**权重决定的实际能力** —— 上下文窗口是架构硬限制、推理能力是参数决定的、
知识截止是训练数据决定的。因此检测必须以"实测能力"为准,元数据只作旁证。

## 1. 探针套件(按不可伪造性排序)

### ① 推理能力阶梯(核心,不可伪造)
精选**参数化题目模板**的分级题库:数字运行时随机生成 → 每次都是新题(无法背题库),
答案程序化精确比对(不依赖 LLM 评判)。题目按模型层级标注区分度:
- T3 旗舰级:前沿模型通过率 >90%,中端模型 <20%
- T2 中端级:T2 模型 >80%,小模型 <10%

结论规则:声称旗舰的模型,T3 题连续 2 次(temperature 0)都失败 → 能力低于声称。
输出"实测能力层级"与"声称层级"比对。

### ② 上下文窗口实测(不可伪造,成本高)
金丝雀埋点 + 填充物,二分探测真实可用上下文:
- 填充文本 + 开头埋 canary("开头的暗号是 X,直接回复 X")→ 模型答不出 = 上下文被截断/伪造
- 二分 3-4 次定位真实上限;声称 200K 实测 8K → 直接实锤
- 同时检测"静默截断":中转站偷偷截断输入省成本(埋点在开头即暴露)

### ③ 知识截止探针(中等,可被 RAG 缓解)
2-3 个冷门但社区有共识答案的近期事件题(非头条,防检索式注入;答案哈希比对)。
声称 2025-06 训练截止的模型答不出 2025-05 的冷门事件 → 训练数据陈旧。

### ④ 随机数分布指纹(研究支持,需参考库)
让模型输出 1-100 随机数 ×N 次,输出分布是模型家族特有的
(Bruckner 行为指纹研究:165 个模型,~120 次短查询可识别替换)。
与各家族参考分布比对可识别"实际是哪个家族"。参考库需采集,放最后。

### ⑤ 降级为参考项(可被网关改写,不参与定罪)
- 响应结构指纹(vLLM 字段等):网关会改写包装
- usage 计数:网关可按声称模型重算
- 身份自述:系统提示注入即可伪造

## 2. 已知局限(诚实边界)

- **同家族版本内替换**(old opus 冒充 new opus):能力阶梯需版本区分度题,较难;
  上下文/知识截止部分可测
- **比例替换**(部分请求真、部分假,API-TAIL 论文场景):单次探测可能恰好命中真模型
  → 需要多次/定期探测提高捕获概率
- **轻度量化替换**:重量化可用能力阶梯/上下文测出,轻度量化难
- **题库泄漏**:参数化模板+数字随机化从根上防;题库文件不进提示词上下文

## 3. KeyDrop 落地形态

- 条目/模型级「深度鉴定」按钮(手动触发,消耗 token):跑探针套件 → 真伪评分 + 证据明细,
  结果入条目档案(复用 modelProbeLog 基建),监控页展示
- 自动模式不做(成本),保持手动深度鉴定

### 成本估算(每次深度鉴定)
- 推理阶梯:2-4 题 × ~1K token ≈ 5-10K tokens
- 上下文实测:二分 2-3 次,填充 token 按探测深度(128K 探测 ≈ 128K 输入)——可选,只对声称大上下文的模型
- 知识截止:2 题 × 小

## 4. 实施分期

- A(先做):推理阶梯(参数化模板+精确比对)+ 条目「深度鉴定」按钮 + 评分/证据展示
- B:上下文金丝雀实测(可选开关,大 payload 成本提示)
- C:知识截止探针
- D:随机分布指纹(需参考分布库采集)
